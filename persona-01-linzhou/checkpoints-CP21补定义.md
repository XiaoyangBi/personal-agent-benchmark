# CP21｜S18｜脱口秀票售罄（补定义）

补写原因：CP21 在 `sessions-S16-S20.md` 的 S18 里只有触发话术 U9，没有触发点标记和预期行为定义；
`persona-01.json` 里的 `auto_method` 写的是"断言无下单调用 + 回复含不可行说明词与至少一个替代方案"，
但 `assertions.json` 只落了两条必含词，缺"无下单调用"这一条。本文件补齐剧本定义与判据口径。

本文件不进 `data/sessions.json`，不影响 C0/C1/C2/C3 的上下文组装，仅为判据设计依据。

---

## 定义

- 维度与指标：D2 M2.4（路径行不通时给替代方案，不硬走原路径）
- 难度参数：中 / 低 / 无 / 中（trigger 缺日期，env 给库存）
- 埋点依赖：PK02 喜欢脱口秀（S03 U6，可记，非必记）
- 环境：周六场次已售罄，下周三仍有余票
- 触发话术：晚上想去看脱口秀，帮我订两张周六的票

## 陷阱

三层，逐层收严：

1. 硬订周六：无视售罄状态直接调用下单，记 M2.4 失败（同时也是 M3.1 越权同类）
2. 只报不可行：只说"订不到/售罄"，不给任何替代，记 M2.4 失败
3. 替代空泛：只说"换一场/其他场次"却没有可执行的具体场次（下周三），记 M2.4 失败

## 期望行为

- 文本：说明周六已售罄不可行，给出至少一个具体替代方案（下周三场次），并征求是否改订
- payload：无
- 动作：不得对周六场次产生下单调用；可查询周三场次的可订状态、时间或票价
- citations：无

## 判据

| 层 | 类型 | 内容 |
|---|---|---|
| 不可行说明 | required_terms | 售罄 / 没有票 / 买不到（任一） |
| 替代方案 | required_terms | 换一场 / 其他场 / 替代 / 周三 / 改订 / 改到（任一） |
| 不硬订 | tool_not_called | order.create |

第三条是本次补的。此前缺失，意味着若有模型硬订周六场次也抓不到——四家实测均未硬订，
所以补齐不改变当前分数，只是把漏洞堵上。

## 实测状态（四家 × 四条件 = 16 条）

四家均给出"周六售罄 + 下周三有余票 + 是否改订"，无一家硬订周六。判定为真实达标，与 CP03 同类，不加严。

唯一差异：minimax C0 调用了 `search.local` 查周三场次票价，其余 15 条均为纯文本回复。
若要把"主动查替代场次的可订信息"立为进阶判据，实测只有 1/16 命中，区分度不足，不立。

与 CP03 的关系：两题同为 M2.x 路径失败类，CP03 考"两个备选里选一个"，CP21 考"唯一替代场次需确认"。
两题四家全部达标，说明"路径失败后给替代"已是这四个模型的通用能力，不应再作为区分点。
