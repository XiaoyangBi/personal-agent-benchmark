- 每条使用新子会话，显式指定 gpt-6.1-sol；只读取该条导出的 messages，写入一次原始 JSON，不共享答题历史，不向答题子会话提供评分判据。

- 输入依据 assertions.json，评分统一依据 assertions-v3.json。后者仅用于离线判分，未注入答题输入。
- JSON 中 tool_calls 是模拟动作声明，未真实执行下单、发消息、建日历等业务。模拟动作声明不等于外部系统执行成功。

- 运行时宿主指令、温度控制和调用路径与直接 API 不同；未暴露温度控制，延迟和输入输出 token 计量缺失。
- GPT 仅一轮，轮间样本标准差、标准误和稳定性均不可估，不以零填写。不做跨轨道 Welch、符号检验或显著性排名，也不计算 CFI。
