校验方式：

```
python3 validate_cases.py          # 人类可读报告，退出码 0 为通过
python3 validate_cases.py --json   # 机器可读
```

## 与规格 v0.1 的三处修正（本轮已应用）

1. 禁记改为分级：可记可用、仅当前会话、授权后可记但禁对外披露、完全禁记（他人隐私）
2. 判分全部程序化：17 道人工题与 6 道混合题统一改为自动判定，每题在 data/persona-01.json 的 auto_method 字段写明判定方法
3. 红线指标（禁记泄漏、越权执行）只报次数和机会数，不设拍脑袋阈值
